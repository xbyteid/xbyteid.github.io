Browser Automation in 2026: Playwright Tips You Actually Need

2026-07-11 · 14 min read · by xbyteid
PlaywrightAutomationTestingPython

Browser automation in 2026 has a clear winner: Playwright. It's faster than Puppeteer, more reliable than Selenium, and supports all three browser engines (Chromium, Firefox, WebKit). I use it daily for HAR capture, data extraction, and automated testing across multiple production services. Here's what I've learned that the docs don't tell you.

Why Playwright Won

  • Multi-browser — test on Chromium, Firefox, and WebKit with the same API
  • Auto-waiting — no more sleep(2) hacks. Playwright waits for elements to be actionable before interacting
  • Network interception — capture, modify, or block any network request
  • Mobile emulation — built-in device profiles for iPhone, Pixel, etc.
  • Codegen — record interactions and generate code automatically
  • Trace viewer — debug failed tests with screenshots, DOM snapshots, and network logs

Installation

# Python
pip install playwright
playwright install chromium  # Install just Chromium (smallest)

# Or install all browsers
playwright install

# For headed mode on Linux (needed for some sites)
playwright install-deps chromium

Basic Automation

Here's a pattern I use for data extraction from dynamic sites:

from playwright.sync_api import sync_playwright

def scrape_dynamic_page(url):
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        context = browser.new_context(
            viewport={"width": 1280, "height": 720},
            user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
        )
        page = context.new_page()
        
        # Navigate and wait for content
        page.goto(url, wait_until="domcontentloaded")
        page.wait_for_load_state("networkidle")
        
        # Extract data
        data = page.evaluate("""() => {
            const items = document.querySelectorAll('.item');
            return Array.from(items).map(el => ({
                title: el.querySelector('.title')?.textContent?.trim(),
                price: el.querySelector('.price')?.textContent?.trim(),
                link: el.querySelector('a')?.href
            }));
        }""")
        
        browser.close()
        return data

Network Interception

Capture all network requests — useful for HAR files, API monitoring, and debugging:

def capture_har(url, output_path="capture.har"):
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        context = browser.new_context(
            record_har_path=output_path,
            record_har_content="embed"
        )
        page = context.new_page()
        
        # Capture API responses
        responses = []
        page.on("response", lambda resp: responses.append({
            "url": resp.url,
            "status": resp.status,
            "content_type": resp.headers.get("content-type", ""),
        }))
        
        page.goto(url, wait_until="networkidle")
        page.wait_for_timeout(3000)  # Wait for lazy-loaded content
        
        context.close()
        browser.close()
        return responses

Stealth Mode

Many sites detect and block headless browsers. Here's how to stay undetected:

from playwright.sync_api import sync_playwright

def stealth_browser():
    p = sync_playwright().start()
    browser = p.chromium.launch(
        headless=True,
        args=[
            "--disable-blink-features=AutomationControlled",
            "--disable-features=IsolateOrigins,site-per-process",
        ]
    )
    context = browser.new_context(
        viewport={"width": 1366, "height": 768},
        user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36",
        locale="en-US",
        timezone_id="America/New_York",
    )
    
    # Override navigator.webdriver
    context.add_init_script("""
        Object.defineProperty(navigator, 'webdriver', { get: () => undefined });
        Object.defineProperty(navigator, 'plugins', { get: () => [1, 2, 3, 4, 5] });
        Object.defineProperty(navigator, 'languages', { get: () => ['en-US', 'en'] });
        window.chrome = { runtime: {} };
    """)
    
    page = context.new_page()
    return p, browser, page

Mobile Emulation

Test mobile views with built-in device profiles:

def mobile_scrape(url):
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        
        # Use built-in device
        iphone = p.devices["iPhone 14 Pro"]
        context = browser.new_context(**iphone)
        page = context.new_page()
        
        page.goto(url, wait_until="domcontentloaded")
        
        # Take mobile screenshot
        page.screenshot(path="mobile-view.png", full_page=True)
        
        # Scroll to load lazy content
        for _ in range(5):
            page.mouse.wheel(0, 500)
            page.wait_for_timeout(500)
        
        content = page.content()
        browser.close()
        return content

Handling CAPTCHAs

Sites with CAPTCHAs require external solving services. Here's the integration pattern:

async def solve_turnstile(page, site_key):
    """Solve Cloudflare Turnstile using an external service."""
    # Get the Turnstile iframe
    frame = page.frame_locator("iframe[src*='challenges.cloudflare.com']")
    
    # Send to solving service (e.g., 2captcha, capsolver)
    solution = await call_captcha_service(
        site_key=site_key,
        page_url=page.url,
        service="turnstile"
    )
    
    # Inject solution
    page.evaluate(f"""
        document.querySelector('[name="cf-turnstile-response"]').value = '{solution}';
    """)
    
    # Submit
    page.click("button[type='submit']")

Proxy Rotation

For scraping at scale, rotate proxies to avoid rate limits:

import random

PROXIES = [
    {"server": "http://proxy1:8080", "username": "user", "password": "pass"},
    {"server": "http://proxy2:8080", "username": "user", "password": "pass"},
    {"server": "socks5://proxy3:1080"},
]

def get_page_with_proxy(url):
    proxy = random.choice(PROXIES)
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        context = browser.new_context(proxy=proxy)
        page = context.new_page()
        
        page.goto(url, wait_until="domcontentloaded")
        content = page.content()
        browser.close()
        return content

Docker Deployment

Run Playwright in Docker for CI/CD or server-side automation:

# Dockerfile
FROM mcr.microsoft.com/playwright/python:v1.44.0-jammy

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .

CMD ["python", "main.py"]
# docker-compose.yml
services:
  playwright:
    build: .
    volumes:
      - ./output:/app/output
    environment:
      - HEADLESS=true
    shm_size: "2gb"  # Required for Chromium

The shm_size: 2gb is critical — Chromium crashes without enough shared memory in containers.

Common Pitfalls

  • Don't use sleep() — use page.wait_for_selector() or page.wait_for_load_state() instead
  • Handle popups — register page.on("popup") handler before clicking links that open new tabs
  • Close contexts — always close browser contexts to free memory. Leaked contexts cause OOM on long-running scripts
  • Use page.locator() over page.query_selector() — locators have auto-wait and better error messages
  • Screenshot on failure — always capture a screenshot when debugging. It's the fastest way to see what the page looked like
Pro tip: Use playwright codegen https://example.com to record interactions in a browser window. It generates Python/JS/Java/C# code as you click, type, and navigate. Perfect for bootstrapping complex automation scripts — then refine the generated code manually.
